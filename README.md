# LanguageChain — نسخه ارتقایافته آموزشی

LanguageChain یک ربات آموزش زبان انگلیسی در تلگرام است که محتوای آن بر اساس شش سطح CEFR از A1 تا C2 دسته‌بندی شده است. این نسخه بر پایه MVP قبلی توسعه داده شده و ساختار SQLite و اطلاعات کاربران را حفظ می‌کند.

## قابلیت‌های این نسخه

### یادگیری واژگان
- ۶۳۷ مدخل یکتای واژه و عبارت در شش سطح A1 تا C2
- معنی فارسی، نقش دستوری، مثال انگلیسی و موضوع واژه
- ثبت وضعیت یادگیری و مرور زمان‌بندی‌شده

### آکادمی گرامر
- ۱۲۰ درس گرامر، ۲۰ درس برای هر سطح
- توضیح فارسی، ساختار، مثال و نکته مربوط به اشتباه رایج
- حرکت مرحله‌ای بین درس‌ها

### مکالمه روزمره
- ۵۴ سناریوی تعاملی در موقعیت‌های اجتماعی، خرید، سفر، سلامت، کار، خدمات، دانشگاه، مذاکره و بحث تخصصی
- کاربر پاسخ را به انگلیسی به‌صورت پیام متنی می‌نویسد
- راهنما، نمونه پاسخ طبیعی و بازخورد مبتنی بر عبارت‌های کلیدی
- ثبت عملکرد و امتیاز تجربه (XP)

### سایر قابلیت‌ها
- آزمون تعیین سطح ۳۰ سؤالی با پنج سؤال از هر سطح A1 تا C2 و نتیجه‌گیری بر اساس عملکرد هر سطح
- ۹۶ سؤال چندگزینه‌ای سطح‌بندی‌شده و تصحیح خودکار
- XP، زنجیره روزهای مطالعه و داشبورد متنی
- مرور لغات و ثبت پاسخ‌ها
- ایجاد گروه، عضویت با کد دعوت و مشاهده اعضا
- منوی بازطراحی‌شده با چیدمان و نشانه‌گذاری بصری بهتر

## نکته مهم درباره گرافیک

رابط اصلی ربات داخل تلگرام از محدودیت‌های ظاهری تلگرام پیروی می‌کند؛ ربات معمولی اجازه ساخت صفحه‌های کاملاً سفارشی، رنگ‌بندی آزاد و نمودارهای تعاملی را نمی‌دهد. برای همین یک نمونه رابط کاربری واکنش‌گرا برای **Telegram Mini App** در پوشه `webapp/` قرار گرفته است.

فایل `webapp/index.html` در حال حاضر یک **نمونه طراحی نمایشی (UI prototype)** است و هنوز به دیتابیس یا API ربات متصل نیست. برای استفاده واقعی در تلگرام باید روی دامنه HTTPS میزبانی شود، سپس API امن و احراز هویت Telegram WebApp به آن متصل و دکمه Web App ربات فعال شود. اعداد داشبورد داخل نمونه نمایشی هستند و داده واقعی کاربر نیستند.

## نصب و اجرا در Windows PowerShell

در پوشه اصلی پروژه:

```powershell
py -3.12 -m venv venv
.\venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item .env.example .env
notepad .env
```

توکن واقعی را فقط در فایل محلی `.env` قرار بده:

```env
BOT_TOKEN=توکن_واقعی_ربات
DATABASE_PATH=languagechain.db
LOG_LEVEL=INFO
```

سپس اجرا:

```powershell
.\venv\Scripts\python.exe -m app.main
```

اگر قبلاً `.env` و دیتابیس داری، آن‌ها را نگه دار و رویشان کپی نکن. نسخه جدید با همان ساختار دیتابیس SQLite قبلی کار می‌کند و نیازی به حذف دیتابیس نیست.

## دستورات
- `/start` نمایش داشبورد و منوی اصلی
- `/help` راهنما
- `/groups` نمایش گروه‌ها
- `/join CODE` عضویت در گروه
- هنگام تمرین مکالمه، نوشتن «لغو» یا `/cancel` تمرین را متوقف می‌کند.

## ساختار مهم

```text
LanguageChain/
├── app/
│   ├── bot/                 # منوها و تعامل تلگرام
│   ├── database/            # SQLite و مخزن داده
│   ├── learning/            # منطق آموزش
│   ├── content.py           # محتوای پایه و اتصال کاتالوگ توسعه‌یافته
│   ├── content_expansion.py # کاتالوگ توسعه قبلی
│   ├── content_reference.py # بانک مرجع گسترش‌یافته
│   └── main.py
├── tests/
├── webapp/                  # نمونه رابط Mini App
├── data/
├── .env.example
└── requirements.txt
```

## آزمون کد

```powershell
.\venv\Scripts\python.exe -m unittest discover -s tests -v
```

## محدودیت‌های صادقانه نسخه فعلی

- بانک فعلی شامل ۶۳۷ مدخل واژه و عبارت، ۱۲۰ درس گرامر، ۹۶ سؤال و ۵۴ سناریوی مکالمه است. این بانک به‌مراتب گسترده‌تر از MVP اولیه است، اما ادعای پوشش تمام واژگان انگلیسی یا تمام کاربردهای دستور زبان را ندارد و باید به‌صورت نسخه‌به‌نسخه تکمیل شود.
- ارزیابی مکالمه فعلاً قانون‌محور و مبتنی بر کلیدواژه است؛ پاسخ‌های هم‌معنی یا خلاقانه ممکن است همیشه درست تشخیص داده نشوند. این نسخه از API هوش مصنوعی پولی استفاده نمی‌کند.
- آزمون تعیین سطح ۳۰ سؤالی، غربالگری آموزشی است و آزمون استاندارد CEFR یا ارزیابی کامل چهار مهارت محسوب نمی‌شود.
- Mini App فعلاً نمونه طراحی است و اتصال به حساب کاربری و دیتابیس در مرحله بعد انجام می‌شود.
- برای انتشار عمومی، باید احراز هویت Mini App، محدودسازی درخواست‌ها، پشتیبان‌گیری خودکار، تست بار و بازبینی امنیتی اضافه شود.

## امنیت

- توکن ربات را در چت یا مخزن عمومی قرار نده.
- فایل `.env` و `languagechain.db` را در اختیار دیگران قرار نده.
- قبل از هر به‌روزرسانی، از `languagechain.db` نسخه پشتیبان تهیه کن.


## نسخه مرجع آموزشی گسترش‌یافته

این نسخه نسبت به نمونه اولیه، بانک محتوای بزرگ‌تری دارد: ۶۳۷ مدخل یکتای واژگان و عبارت (شامل واژه‌های موضوعی، افعال عبارتی، اصطلاحات و هم‌آیی‌ها)، ۱۲۰ درس گرامر سطح‌بندی‌شده، ۹۶ سؤال چهارگزینه‌ای و ۵۴ سناریوی مکالمه تعاملی. محتوا برای سطوح A1 تا C2 تفکیک شده است.

این اعداد به معنی پوشش کامل تمام واژگان یا دستور زبان انگلیسی نیستند؛ یک کاتالوگ مرجع قابل توسعه‌اند. برای محصول آموزشی جدی، محتوای هر درس باید در چرخه‌های بعدی با ویراستار زبان، فایل صوتی تلفظ، تمرین‌های تولیدی و آزمون‌های مهارتی تکمیل شود. ارزیابی مکالمه در این نسخه همچنان مبتنی بر کلیدواژه است و معادل ارزیابی معنایی انسانی یا هوش مصنوعی نیست.
