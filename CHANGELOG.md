# Changelog — LanguageChain Reference Edition

## 2.1.0
- Expanded the vocabulary and expression bank to 637 unique entries across A1–C2.
- Added topic tags, phrasal verbs, idioms and collocations.
- Expanded grammar curriculum to 120 lessons (20 per CEFR band).
- Expanded multiple-choice quiz bank to 96 questions (16 per band).
- Expanded interactive role-play library to 54 scenarios across A1–C2.
- Replaced the six-question placement check with a 30-question screening set (five per level), with level-by-level scoring.
- Added pagination to the conversation picker to avoid a long, cluttered Telegram keyboard.
- Kept the SQLite schema and existing user/group data model unchanged.
- Added automated content validation tests.

## Important limitations
- The placement test is an educational estimate, not an official CEFR certification.
- Conversation feedback is deterministic keyword matching, not semantic assessment.
- The Mini App remains a visual prototype and is not yet connected to the bot database/API.
